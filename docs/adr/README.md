# `adr/` (Architecture Decision Records)

Katalog przeznaczony na rejestr decyzji architektonicznych (ADR). 

Każda kluczowa zmiana w architekturze, technologii lub sposobie organizacji projektu powinna zostać udokumentowana jako nowy plik w tym folderze (np. `0001-przejscie-na-zod.md`, `0002-wybor-bazy-danych.md`). 

Dzięki temu nowi członkowie zespołu oraz agenci AI mogą łatwo prześledzić historyczny kontekst i powody, dla których kod wygląda tak, a nie inaczej.
